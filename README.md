# HealthMind 🧠

HealthMind is an AI-powered personal health and behavior intelligence system that helps users understand patterns in their daily habits, mood, sleep, and stress — and guides them toward healthier routines using agentic AI.

## Key Features
- Identity-aware personalization
- Long-term behavioral memory
- Pattern detection using machine learning
- Agentic planning and habit support
- Privacy-first, non-medical AI system

## What HealthMind Is Not
HealthMind does not provide medical diagnosis or treatment and is not a replacement for healthcare professionals.

## Tech Stack
- FastAPI
- LangChain
- LangGraph
- Machine Learning 
- Vector Memory
- PostgreSQL
